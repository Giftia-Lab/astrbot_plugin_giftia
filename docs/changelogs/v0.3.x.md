# v0.3.x 更新日志

[返回最新更新日志](../../changelog.md)

## [v0.3.9] - 2026-10-13

### Refactor

- **统一媒体转述模型与重试配置**：`image_caption_provider_ids`、`audio_caption_provider_ids`、`video_caption_provider_ids` 合并为 `media_caption_provider_ids`；三类 `*_caption_retry_times` 合并为 `media_caption_retry_times`，表情包分析共用同一配置。升级后需重新选择媒体转述提供商，不自动迁移旧配置。
- **非活跃会话固定延迟转述**：移除 `defer_caption_enabled` 配置及条件分支，媒体默认仅缓存，按需查看时再转述。

### Bugfix

- **媒体开关覆盖主动查看与表情包分析**：保留图片、音频、视频独立开关，关闭后不发起对应模型请求，已有缓存可继续通过工具读取；修复视频开关未生效的问题。

## [v0.3.8] - 2026-09-27

### Refactor

- 统一代码格式与 Ruff 规范，清理导入、空白及未使用代码。

### Bugfix

- 修复日志导入违规，并移除 SSL 证书验证失败时关闭校验的高风险回退。

## [v0.3.7] - 2026-09-27

### Features

- **决策审计展示优化**：WebUI 决策审计新增「并入本轮回复」类型及消息处理状态标签。

### Refactor

- **会话消息按批次串行处理**：同一会话的接话决策与正式回复串行执行，冷却和回复期间的新消息自动合并保留，不再丢弃或挂起；决策通过后自动并入正式回复开始前的新消息。
- **并发配置调整为「会话批处理」**：支持配置会话决策最小间隔、会话消息防抖、会话最大合并等待和每批待处理消息上限（沿用原有时间设置）；机器人「主动接话分析窗口」改为按决策轮数计算。

## [v0.3.6] - 2026-09-20

### Bugfix

- **修复消息流转阻塞**：Giftia 的媒体解析、接话判断和正式回复改为后台执行，其他插件无需等待 Giftia 完成处理即可继续读取消息。

## [v0.3.5] - 2026-09-15

### Features

- **任务看板支持新建任务**：右下角「刷新」按钮改为「新建」，短期任务和定时任务分别提供对应的创建表单。
- **支持从看板创建定时任务**：创建时保留当前会话的平台路由信息，确保群聊和私聊提醒发送到正确位置。

### Bugfix

- **修复短期任务清空失败**：补齐数据库清空接口，清空按钮可按当前会话和分类正常执行。
- **修复短期任务创建成功却提示失败**：兼容插件页面桥接返回的数据结构，避免将任务自身的 `active` 状态误判为接口失败。

## [v0.3.4] - 2026-09-13

### Features

- **私聊可选前置决策**：WebUI「触发与接话策略」新增「私聊启用前置决策」开关，默认关闭；开启后允许的私聊消息先由小模型判断是否回复。

### Refactor

- **群聊接话决策默认启用**：移除机器人配置中的前置决策和正式回复开关，群聊按现有触发与 @ 策略自动处理；允许的私聊默认直接回复。
- **机器人配置界面调整**：将「关联 AstrBot 人格」移至「身份与适配器」页签；「正式回复」页签改为单列布局，并统一使用「前置决策」「正式回复」命名。

## [v0.3.3] - 2026-09-12

### Features

- **群聊与私聊名单分开管理**：群聊默认使用黑名单，私聊默认使用白名单；WebUI 新增「会话黑白名单」页签，可分别配置两类会话。
- **新增私聊名单指令**：管理员可使用 `/开启私聊`、`/关闭私聊` 按用户 ID 或 @用户管理私聊权限；`/说话`、`/闭嘴` 支持管理当前或指定会话。
- **新增用户屏蔽指令**：使用 `/屏蔽`、`/取消屏蔽` 管理指定用户在当前 Bot、当前会话中的发言权限。
- **名单限制即时生效**：未允许的会话和被屏蔽用户不会入库或触发回复，@消息与定时提醒也遵守名单。

> **升级提示：** 更新到 v0.3.3 后，请在 WebUI「会话黑白名单」页签重新配置群聊和私聊黑白名单。

## [v0.3.2] - 2026-09-09

### Refactor

- **工具简化**：将设置头像描述工具降级为xml交互工具，可减少一轮工具调用。

### Bugfix

- **修复撤回、点赞、禁言、踢人、贴表情、戳一戳与消息的执行顺序**：统一按 XML 中的位置执行，退群仍在最后执行；撤回失败不再影响后续复读。
- **修复 XML 工具输出乱序**：工具与消息按 XML 顺序执行，工具返回的图片及时发送，避免被后续工具输出抢先。
- **修复操作日志时间错位**：按动作实际完成时间记录，保持聊天历史中的先后顺序。
- **修复引用消息转特征音时的空消息与引用丢失**：引用随第一段实际内容发送。

## [v0.3.1] - 2026-09-08

### Bugfix

- **补充小程序与卡片消息解析入库**：
  - 支持解析并提取 QQ 小程序与卡片分享消息（JSON / Ark 卡片）中的关键内容（如标题、描述、链接及应用来源），补齐消息上下文解析能力并规范化存入聊天历史。

## [v0.3.0] - 2026-09-08

### Features

- **支持会话黑话（群梗/专有名词）管理与上下文自动注入**：
  - 支持基于机器人与会话隔离的黑话词条持久化存储；
  - 新增 `/黑话` 指令：全员支持按词条查询释义，管理员支持通过 `/黑话 词条 释义` 新增或覆盖词条；
  - 大模型交互支持通过 XML 动作标签自主管理黑话（`<slang action="set" ...>` 与 `<slang action="delete" ...>`），在日常闲聊中自主学习和遗忘群梗；
  - 对话决策与回复阶段自动检索并注入当前上下文中命中的黑话词条，增强对群聊特定黑话与圈内梗的理解和运用；
  - Web 控制台新增「黑话管理」面板。
- **常规配置新增防流口水过滤开关 (`enable_anti_drool`)**：
  - 允许在常规配置中自主决定是否启用对重复外显消息的抑制，默认关闭（建议能力较差模型开启，优质模型保持关闭以避免影响正常输出）。

### Refactor

- **Web 控制台顶部导航栏重构与自定义排版**：
  - 顶部导航栏重构为「常驻页签区 + “更多”下拉收纳」结构，避免页签过多在窄屏/分屏场景下挤压溢出；

### Bugfix

- **修复外显消息输出时序队列与下标错位 Bug**：
  - 修复防流口水重构 `output_order` 时未同步处理 `sticker`/`image`，导致表情包索引错位并引发后续文字消息重复发送两次且双份入库的严重 Bug；
  - 修复 TTS 特征音切分时 `output_order` 映射遗漏多媒体类型的问题；
  - 修复定时任务/提醒唤醒中表情包与图片外显被静默丢弃的问题；
  - 将 `<repeat>` 复读动作正式纳入 `output_order` 统一时序派发队列，彻底消除复读与常规消息先后颠倒乱序的问题；
  - 修复 XML 解析独立多媒体标签时 `msg_texts` 长度与 `msg_chains` 未 1:1 对齐的问题。
  - 补充报告模板缺少的图片素材删除管理。
