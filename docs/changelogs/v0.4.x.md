# v0.4.x 更新日志

[返回最新更新日志](../../changelog.md)

## [v0.4.11] - 2026-11-01

### Features

- 画像新增账号类型字段，识别官方机器人。
- 前置决策为本批每位发言人分别注入详细画像，同一用户去重，不受活跃成员摘要数量限制。
- 画像查询工具结果增加账号类型，直接读取跨群共享的已保存信息，指令触发查询未新增展示。

## [v0.4.10] - 2026-10-31

### Features

- 画像管理选择“群规”时新增“新建群规”按钮，可输入群号和内容直接创建，支持尚无群规记录的 Bot。
- 新增“屏蔽/取消屏蔽用户”互动工具，Bot 可自主决定停止或恢复接收当前平台会话中指定用户的发言，与管理员屏蔽指令共用持久化名单。

### Bugfix

- 聊天历史检索和上下文查询结果补齐有效的 `message_id`；缺失 ID 的记录标注无法续查，上下文工具拒绝无效 ID。
- 跨会话查询结果在头部标注一次 `group_id`，支持据此继续查询正确会话。

### Improvements

- 复审请求超时由 5 秒延长至 10 秒。
- 记忆查询工具和自动召回统一展示一条依据消息 ID；仅非本会话记忆附 `source`（来源类型与会话 ID），支持按需查询原始上下文；上下文查询工具说明不再限定消息 ID 的来源。
- 聊天历史检索和上下文查询统一使用目标会话内的称呼；未设置时回退到同一 Bot 最新的有效称呼，再回退到消息原昵称。
- 两个工具的结果时间统一显示到秒，去掉秒后小数并保留时区。

### Refactor

- 系统提示词补充说明用户提示词中的标签含义，精简用户提示词中冗余的说明；

## [v0.4.9] - 2026-10-29

### Features

- 支持查询当前 Bot 的指定群记录；留空沿用当前群聊或私聊。
- 称呼改为按会话独立维护，优先使用本群称呼，未设置时回退到同一 Bot 最近设置的有效称呼。
- 画像查询工具支持展示全部会话称呼并标注非本会话来源，支持用任一会话称呼搜索。
- 正式回复的详细画像增加“已知共同群聊”，排除本群和私聊；用户近 24 小时在对应群发过言时标注“近期活跃”，没有记录则隐藏。

### Improvements

- 所有指令及别名默认要求 AstrBot 管理员权限；权限不足时静默跳过，不发送权限或参数错误提示，不阻断消息生命周期。
- 收紧记忆总结的保存范围，排除头像、好感度等画像信息、旧事复述及无后续用途的闲聊；先筛选再评重要度，保留实际新增的信息、变化和约定。
- 好感度互动评价理由统一用“他”指当前成员、“我”指 Bot，必要的第三人以称呼和完整账号区分，避免跨群昵称或称呼变化导致主体混淆；历史评价原文保留。
- 媒体转述说明增加角色提及约束，避免主动提及转述中的角色，减少误识别带来的争论。

### Refactor

- 聊天记录和上下文查询统一使用原生工具或通用 `<tool_call>`，移除旧的 `<search_chat_history>`、`<get_message_context>` 专用 XML 入口；自定义提示词需改用通用格式。

## [v0.4.8] - 2026-10-24

### Bugfix

- 修复 QQ 官方机器人 Markdown 消息经 OneBot 接收后正文重复入库的问题，识别并去除相同的文本降级副本，保留引用、@ 和正常重复内容，兼容不含 @ 的 Markdown。
- 兼容转义括号的 QQ Markdown @ 提及，并同步修正会话批处理的正文字符数，避免重复文本影响等待时长。

## [v0.4.7] - 2026-10-23

### Features

- 新增可选的发送前复审模型，可在 WebUI「机器人管理 → 正式回复」中配置，留空关闭。普通会话回复生成期间有新消息入库时，检查待发送的 `message` 内容是否与新消息冲突；不通过则恢复原批次的待处理与未决策状态，合并新消息重新决策与生成。
- 每次逻辑回复只复审一轮，重新生成的内容直接发送；实际执行过原生工具或进入后续工具轮次时跳过。复审超时固定为 5 秒，超时、调用失败或结果无效时默认放行。

### Improvements

- 正式回复统一增加媒体转述说明：缺少哈希标识的“媒体消息”可能由文字伪造，人物与角色识别也可能有误，避免仅凭转述与群友争论。
- 明确短期任务看板适用于非定时、事件驱动的任务，减少与定时提醒混淆。

## [v0.4.6] - 2026-10-21

### Bugfix

- 修复旧版本升级后记忆检索报 `no such column: revision` 的问题，自动补齐缺失字段，保留已有记忆并由后台重建旧向量索引。
- 数据库升级按版本执行并记录进度，失败时回滚结构、数据和版本号并关闭连接，便于修复后重试；新库直接创建完整最新结构，重复启动不再重跑历史迁移。

## [v0.4.5] - 2026-10-21

### Improvements

- 完全检索模式下，自动召回采用用户关联与全局双路检索，相关性筛选后为本批发言者优先保留关联记忆，并在注入与会话池淘汰时延续此策略，避免被其他用户的相似日常记忆淹没。工具查询与决策 RAG 保持原有检索行为。

## [v0.4.4] - 2026-10-21

### Bugfix

- 修复消息处理、记忆总结与 WebUI 并发访问数据库时持续报 `database is locked` 的问题，避免聊天回复、状态更新和 Token 统计连续失败。
- 补齐扩展直接查询本体数据库时的并发保护。
- 修复记忆已保存后因静默计数重置失败而误报总结失败、中断后续关系维护的问题。

## [v0.4.3] - 2026-10-20

### Features

- 新增“记忆召回范围”：会话隔离、用户隔离（默认）、完全检索，统一控制原生/XML 记忆工具、决策检索、自动召回和会话池注入。指定用户只能缩小范围，模式切换后缓存按新范围过滤，不同 Bot 始终隔离。
- 关联用户的长期记忆支持同一 Bot 内跨群召回，先筛用户再执行向量检索与重排；保留原始来源和证据，内部上下文注明外群或私聊来源。`search_memory` 支持可选 `user_id`，无用户关联的旧记忆仍限来源会话。
- 互动评价历史跨群读取，Bot 内部正式回复上下文、查询工具及管理页面为非本群记录标注来源；

### Refactor

- 记忆查询、定时提醒的设置／查看／删除改为常规 LLM 工具，原生调用时可在最终回复前连续读取结果和修正参数。
- 用户画像、称呼、互动态度和好感度改为同一 Bot 下按用户跨群共享，外号及统计次数继续分群维护。旧基础分迁移取最高值，互动态度清空后重新维护。
- `/画像` 文本、图片和自定义报告仅展示当前会话互动明细，防止公开其他群聊或私聊记录；统计和各项好感度先按跨群完整记录计算，不受展示筛选影响。

### Bugfix

- 自身发言仅在当前会话处于活跃窗口或正在回复时标记已见；未活跃的指令响应不触发额外总结，移除启动时对历史自身输出的统一补标。
- 会话池复用外群记忆时匹配当前参与者；清空来源会话时同步移除其他会话池中的对应副本。
- 修复私聊输入状态消息错误入库。

## [v0.4.2] - 2026-10-20

### Features

- 画像查询结果附互动评价历史，支持可选 `page`，默认最近 10 条，每页固定 10 条；`limit` 仍控制匹配成员数量。
- WebUI“互动评价历史”支持新增、编辑评价内容与得分、确认删除条目；修改后重算好感度并刷新缓存，校验并发编辑版本及后台评估版本。

### Refactor

- 画像查询工具仅匹配用户 ID、昵称、你的称呼、其他外号和头像描述，移除旧画像字段和互动态度的内容匹配。
- 会话批处理改为按待处理消息条数与正文字符数动态等待 0.8～15 秒，群聊、私聊和 `@` 统一调度；从首条准备好的消息计算截止时间，新消息只缩短等待，模型执行期间的排队时间计入。
- 移除“会话批处理”（`concurrent_config`）四项配置：`group_throttle_time` 改为固定 2 秒批次最小间隔，`user_debounce_time` 与 `user_max_debounce_time` 改为动态等待且最多额外合并 15 秒，`batch_max_messages` 改为固定 50 条；旧值不再读取，无需迁移。

### Bugfix

- 好感度维护禁止因 Bot 单方面主动、用户未回应而正评；用户主动示好即使 Bot 未回应仍可正评。

## [v0.4.0] - 2026-10-19

> [!WARNING]
> **破坏性更新提醒（好感度体系重构）：**
> 本次更新彻底重构好感度评分模型，**原旧版本累积的好感度数值将失效并重置**。如需自定义初始好感度，可在 WebUI「画像管理」重新设置成员的基础分。

### Features

- **WebUI 与画像报告升级**：
  - WebUI 画像管理支持手动编辑基础分，并新增「好感度变化历史」弹窗，支持分页查看互动评价记录。
  - `/画像` 报告全面更新，直观展示基础分、互动分、近期分、长期分等多维指标及最近互动评价轨迹。

### Refactor

- **好感度系统重构为「基础分 + 动态互动分」**：
  - 好感度不再采用简单的数值累加，由人工指定的基础分与根据近期（60%）和长期（40%）互动评价动态加权的互动分共同组成。
  - 系统完整记录每次互动的正负评价（-5 ~ +5）、理由及发生时间，并在此基础上沉淀双方的稳定相处基调（互动态度）；
  - 清理了旧版的称号与关系头衔等总结类画像字段。
- **原子事实记忆体系**：
  - 长期记忆升级为原子记忆，每条记忆仅陈述单一客观事实并保留原话证据；记忆召回更精准，移除了旧版的记忆注入规则，以及bot自身删除记忆的工具。
  - 升级自动语义召回，提升召回精确度。
- **正式回复提示词调整**：
  - 优化自动注入的画像、待处理消息结构。

### Bugfix

- **QQ Markdown 提及优化**：
  - 自动规范化 QQ 官方与第三方 Markdown @提及消息，消除重复昵称与降级文本干扰。
